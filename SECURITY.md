# Política de seguridad

## Versiones compatibles

La rama `main` contiene la única versión con mantenimiento activo.

## Reporte de vulnerabilidades

No publiques vulnerabilidades, credenciales, datos personales o información de la base de datos en un issue abierto. Utiliza el reporte privado de vulnerabilidades de GitHub si está habilitado; de lo contrario, comunícate de forma privada con el propietario del repositorio.

Incluye una descripción clara, los pasos mínimos para reproducir el problema, el impacto observado y cualquier propuesta de corrección. El reporte será revisado antes de divulgar información públicamente.
